# bench-link v1: USB protocol between the STM32 and the bench HMI

Binary protocol on the STM32 USB CDC port (`/dev/ttyACM0`). It replaces the
earlier text console of this branch. Sources of truth:

- firmware: `stm32/App/Inc/link/bench_frame.h`, `stm32/App/Inc/link/bench_proto.h`;
- host: `hmi/benchlink/protocol.py`;
- shared golden frames: `stm32/tests/vectors/bench_link.txt`, generated by
  `hmi/tests/vectors.py`, checked byte for byte by `stm32/tests/test_bench_link.c`
  and `hmi/tests/test_contract.py` (IDs and sizes are also read from the C header).

Change the protocol only by changing both sides, regenerating the vectors and
incrementing `BL_PROTO_MINOR` (now 2: CTRL, CTRL_PARAMS, capability bit 0x0008; 2 adds the integrator gains and the EKF flag; 3 adds CTRL_GAINS; 4 adds the XY/yaw reference and the battery factor to CTRL) (compatible) or `BL_PROTO_MAJOR` (incompatible).

## Framing

```text
packet = id (u8) | seq (u8) | payload (0..96 bytes) | crc16 (u16 LE)
wire   = COBS(packet) | 0x00
```

- CRC-16/CCITT-FALSE (polynomial 0x1021, initial 0xFFFF) over id, seq and payload.
- A lone `0x00` (empty frame) is ignored and can be used to resynchronize.
- Frames longer than the maximum, bad COBS or bad CRC are discarded and counted.
- `seq` increments per frame on each side. The host detects lost device frames
  from gaps; the device echoes the command `seq` in its ACK.
- All multibyte fields are little-endian; `f32` is IEEE 754 binary32.

## Session and safety rules (firmware)

- Opening the port with DTR starts a session: motors stop, pending bytes and
  queued telemetry are discarded, and the STM32 sends `HELLO`. Closing the port
  (DTR low) stops the motors.
- `HEARTBEAT` is the only message that renews the 300 ms bench keepalive. The
  HMI sends it every 100 ms while the controlling browser page is alive.
- `ARM` requires a `HEARTBEAT` in the last 300 ms, no RX overflow, and, if a
  minimum battery voltage was configured, a calibrated reading above it.
- Corrupt frames, unknown commands and out-of-range fields stop the output and
  are answered with `ACK` result 2 (invalid) or 3 (unknown) when an id is known.
- RX overflow stops the output and blocks commands until reconnecting.
- Direction and beep are accepted only while disarmed with everything at zero.
- Bench throttle never exceeds the cap (40 % after every boot, 0–100 %).
- The control owner (owner 2 in STATUS) writes the motors directly up to its own
  limit (95 % at boot, from CTRL_PARAMS). It disarms without a controller update
  for 100 ms and without HEARTBEAT for 300 ms, like the bench owner.

## Device → host messages

Times `t_ms` are the STM32 tick in ms. Units are SI unless stated.

| id | name | size | rate | content |
| --- | --- | --- | --- | --- |
| 0x01 | HELLO | 40 | per session / on request | proto major, minor (u8), capabilities (u16), uptime ms (u32), firmware id (24 ASCII, `manifest.json` `firmware_id`), build variant (8 ASCII) |
| 0x02 | STATUS | 32 | 10 Hz | t_ms, flags, owner (0 none, 1 bench), cap ‰, ramp ‰/s, 4 × target ‰, reversed mask, direction-sent mask, direction-confirmed mask (always 0: no readback), pending special commands, DShot transmit failures, heartbeat age ms (0xFFFFFFFF = never), IMU divider, reserved |
| 0x10 | IMU | 72 | each BNO rotation report / divider (400 Hz) | t_ms, quaternion w,x,y,z, gyro x,y,z rad/s, linear acceleration x,y,z m/s² without gravity (BNO085 axes), accuracy rot/gyro/lin (0–3), flags (bit0 online), report counts ×3, report gaps ×3 |
| 0x11 | RANGE | 42 | each MTF-01 frame (100 Hz) | t_ms, sensor ms, distance mm (sensor axis), flow x,y (i16, cm/s at 1 m — not velocity), quality, distance status, flow status, strength, precision, flags (bit0 range valid, bit1 flow valid), frames, CRC errors, gaps, UART errors, dropped bytes |
| 0x12 | MOTOR | 22 | 100 Hz | t_ms, flags (bit0 armed), 4 × sent ‰, 4 × DShot 11-bit value accepted by DMA, KISS request mask of that frame |
| 0x13 | ESC | 23 | each KISS frame | t_ms, motor index 0–3, temperature °C (i8), voltage cV, current cA, consumption mAh, eRPM/100, frames OK, timeouts, reserved |
| 0x14 | POWER | 21 | 10 Hz | t_ms, PA1 pin V, PB0 pin V, battery V, current A (f32), flags: bit0 PA1 read, bit1 PB0 read, bit2 battery calibrated, bit3 current calibrated |
| 0x15 | SYS | 68 | 1 Hz | t_ms, telemetry dropped, free heap B, link packets, link errors, RX overflows, ESC CRC/length/unsolicited/UART errors, ESC timeouts ×4, BNO errors, BNO resets, BNO fault code, 3 reserved |
| 0x16 | CTRL | 96 | 20 Hz | t_ms, state (0 disarmed, 1 armed, 2 spool, 3 climb, 4 hover, 5 land), flags (bit0 Kalman free, bit1 range ok, bit2 flow ok, bit3 BNO ok, bit4 trim active, bit5 motor limited, bit6 XY in the controller, bit7 battery compensation), last stop reason, 9 × f32 measurements `y = [z φ θ ψ u v p q r]` (NED/FRD, SI), 3 × f32 position x̂ (m, z down), 3 × f32 velocity (m/s), height reference m, trim ‰, base throttle ‰ (before battery compensation), x/y reference m (local), yaw reference rad, battery factor |
| 0x20 | TEXT | 5–65 | events | t_ms, level (0 info, 1 warn, 2 error), up to 60 characters |
| 0x21 | ACK | 5 | each command except HEARTBEAT | command id, command seq, result (0 ok, 1 rejected, 2 invalid, 3 unknown), value (u16; applied cap for CAP) |

STATUS flags: bit0 armed, bit1 sweeping, bit2 heartbeat fresh, bit3 RX blocked,
bit4 ESC telemetry requests on, bit5 data stream on, bit6 battery below minimum.

A DShot value is never reported as RPM. RPM comes only from ESC telemetry:
`RPM = eRPM / (poles / 2)`, with the pole count set in the HMI.

## ESC KISS telemetry

USART1 RX on PA10 at 115200 8N1, wired from the KM55A II TX pad. The AM32 frame
(`references/AM32/Src/kiss_telemetry.c`) is 10 bytes: temperature, voltage,
current, consumption, eRPM/100 (big-endian) and CRC8 (polynomial 0x07). The
four ESCs share one TX line, so only one motor has the DShot telemetry bit per
request; the reply is attributed to that motor if it arrives within 8 ms.
Special commands (beep, direction) set the bit on all four, so replies in the
following 20 ms are counted as unsolicited and discarded. Logic and tests:
`stm32/App/Src/actuators/esc_kiss.c`, `stm32/tests/test_esc_kiss.c`.
