# Referências locais de desenvolvimento

Esta pasta guarda conversas completas e outros materiais brutos usados durante
o desenvolvimento. Esses arquivos são ignorados pelo Git porque são grandes,
podem conter caminhos locais e não passaram pela mesma revisão da documentação
técnica.

Conclusões que continuam válidas devem ser consolidadas nos documentos da
pasta `docs/` ou em comentários próximos do código correspondente. Os chats
não são especificação do firmware.
